CPU Jr. Backup Privacy Policy

Effective date: November 2, 2026

CPU Jr. Backup is a personal application for backing up a Raspberry Pi to Google Drive. This policy explains what data the application accesses, how it is used, and how you can control it.

Data the application accesses

  • Google Drive files created by the application. Google Drive access is used to create, manage, retrieve, and delete the application's backup files.
  • Google OAuth credentials. The authorization tokens needed to reach Google Drive are stored locally on the owner's Raspberry Pi.
  • Raspberry Pi system files. The files selected for backup are read on the device in order to create backups.

How data is used

Data is used only to create, store, verify, and restore backups of the owner's Raspberry Pi. Backup contents are encrypted locally on the Raspberry Pi before they are uploaded to Google Drive, so the files stored in Google Drive cannot be read without the owner's encryption key.

Data sharing

Data is not sold, shared with third parties, or used for advertising. No data is sent to any server other than Google Drive. The application has no analytics or tracking.

Google API Services User Data Policy

CPU Jr. Backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

Encrypted backup files remain in the owner's Google Drive account until they are deleted, either by the application's backup-pruning process or manually by the owner. OAuth credentials remain on the Raspberry Pi until they are removed or access is revoked.

Your controls

  • Revoke the application's access to Google Drive at any time from Google Account → Third-party connections.
  • Delete backup files directly in Google Drive.
  • Delete the locally stored credentials from the Raspberry Pi.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date.

Contact

Questions about this policy can be raised by opening an issue at github.com/ickiwas-ui/cpu-jr-backup-info.
