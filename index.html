CPU Jr. Backup

CPU Jr. Backup is a personal backup application that uses Rclone and Restic to store encrypted Raspberry Pi system backups in Google Drive.

How it works

  • Restic creates backup snapshots of the Raspberry Pi and encrypts them on the device before anything is uploaded.
  • Rclone transfers the encrypted backup files to the owner's own Google Drive account.
  • Backups can be listed, pruned, and restored from the Raspberry Pi.

Use of Google Drive

Google Drive access is used only to create, manage, retrieve, and delete the application's backup files.
